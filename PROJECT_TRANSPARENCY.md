# Прозрачная карта проекта (простыми словами)

Этот документ объясняет проект простым языком.

## Как устроен проект
- `app/` — backend на FastAPI.
- `tests/` — автоматические тесты backend.
- `frontend/` — frontend часть (Vite/TS).
- `requirements.txt` — список библиотек Python.
- `Dockerfile`, `docker-compose.yml` — запуск в контейнерах.

## Что делает каждая группа файлов

### 1) `app/main.py`
- Создает приложение FastAPI.
- Подключает CORS (разрешенные адреса фронтенда).
- Подключает все роутеры (`users`, `auth`, `students`, и т.д.).
- Возвращает `{"status": "ok"}` на `/`.

### 2) `app/database.py`
- Создает подключение к базе данных.
- Создает `SessionLocal` для работы с БД.
- Дает `Base` для моделей SQLAlchemy.

### 3) `app/dependencies.py`
- Функция `get_db()` выдает сессию БД в API-методы.

### 4) `app/security.py` и `app/auth.py`
- Хеширование паролей.
- Проверка паролей.
- Работа с JWT токеном (токен доступа).

### 5) `app/models/*.py`
- Описание таблиц базы данных.
- Поля, связи между таблицами.

### 6) `app/schemas/*.py`
- Описание входных/выходных данных API (Pydantic схемы).
- Валидация данных.

### 7) `app/routers/*.py`
- API-эндпоинты для сущностей:
  - пользователи,
  - авторизация,
  - ученики,
  - родители,
  - филиалы,
  - секции,
  - посещаемость,
  - уроки,
  - оплаты,
  - замены.

### 8) `tests/test_auth_students.py`
- Проверка логина.
- Проверка, что `students` требует токен.
- Проверка полного CRUD цикла учеников.

## Простые объяснения терминов
- **CRUD** — создать, прочитать, обновить, удалить.
- **JWT** — строка-токен, как пропуск в защищенные ручки.
- **CORS** — правило браузера, кому можно ходить в API.
- **Session (SQLAlchemy)** — объект, через который делаем запросы к БД.
- **commit** — сохранить изменения в БД.
- **flush** — отправить промежуточные изменения в БД без финального сохранения.
- **refresh** — перечитать объект из БД, чтобы получить актуальные данные.

## Как запускать
1. Установить зависимости:
   - `pip install -r requirements.txt`
2. Запустить backend:
   - `uvicorn app.main:app --reload`
3. Запустить тесты:
   - `pytest -q`
